# NoitaAutoAspectRatio
A mod that automatically adjusts the GUI resolution scale based on your current resolution.

In short, this allows the game to support resolutions like 16:10 without any black bars.

Since it needs to modify config.xml in the save directory, it relies on the unsafe feature, making it impossible to upload to the Steam Workshop.


自动根据当前分辨率更改gui分辨率比例的模组。

简而言之这将让游戏支持列如16：10的分辨率并且不存在黑边。

因为需要更改存档的config.xml，所以使用unsafe功能实现，导致无法上传创意工坊。
